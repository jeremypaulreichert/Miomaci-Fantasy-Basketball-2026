# Miomaci Fantasy Basketball 2026

A compact companion to the Miomaci AI fantasy basketball experiment.

Ten configured AI managers completed a shared 130-pick snake draft and ten separate 13-player rosters. The aim is to describe how these systems make choices, not establish which company is most intelligent. See [Methods and limitations](METHODS.md).

The JSON files contain selections, player names, configured model labels, narrow activity fields and roster-overlap summaries. Raw journals, account records, requests, responses, research articles, screenshots and working history are withheld. Player names are public sports information. Model labels describe recorded configuration, not independent identity certification.

Run `python verify.py` using Python 3.11 or newer for offline integrity and arithmetic checks. It uses only the standard library, reads this folder, and makes no network calls. Passing it checks the companion files; it does not authenticate hidden originals or certify the entire experiment.

The private original archive remains intact. The origin and scope of this projection are recorded in `provenance.json`; companion file hashes appear in `MANIFEST.json`. Hashes cannot reconstruct withheld sources. This companion is a post-draft projection and does not inherit the old archive's byte hashes, external timestamp proof or preregistration status.
